# Geographic layer programs (#49)

Status: the seven-family catalog, public adapters, Rust interaction processor,
browser controller and optional MapLibre shell define the #49 implementation.
The bounded native/WASM and browser conformance scope is recorded below;
spatial tiers and massive-source work in #50 remain pending.

## Ownership and reuse

Rust consumes retained GeoColumn data and the explicit GeoViewport, resolves
styles, projects/clips/tessellates, constructs canonical Scenes, and preserves
source feature identity and complete direct-density membership. TypeScript frames typed
inputs and paints the existing Scene programs. MapLibre is an optional,
app-supplied camera/basemap shell. The default package imports no MapLibre,
provider, token, remote asset or tile service.

The catalog has seven families, with labels and legend entries authored as
layer properties rather than additional families:

| Family | Source geometry | Scene representation |
| --- | --- | --- |
| `points`, `bubbles` | Point / MultiPoint | Scatter with resolved per-instance size and style |
| `routes`, `arcs` | LineString / MultiLineString | Explicit two-vertex Segment records |
| `polygons`, `choropleth` | Polygon / MultiPolygon | Explicit three-vertex Triangle fills and source-edge Segment outlines |
| `density` | Point / MultiPoint | Top-first RGBA Image, complete contributor CSR and state overlays |

Scene32 explicitly frames Triangle6 and Segment7 primitives. Repeated feature
IDs do not join adjacent triangles or routes. XYPB15 batches their existing
GPU programs and varied Scatter instances; density reuses the texture program.
Labels and legends reuse Rust-resolved Scene sidecars and existing DOM/SVG
consumers. A separate geographic painter or host projection is not permitted.

The detailed [compiler](geo-layer-compiler.md) and
[packed transport](geo-layer-protocol.md) contracts are authoritative for
defaults, numeric framing and admission. The
[capability matrix](geographic-capabilities.md) records bounded evidence,
competitor reference points and remaining gaps. The offline seven-family
example is [SVG](../assets/geographic-catalog.svg) /
[PNG](../assets/geographic-catalog.png), generated by
`uv run python examples/geographic_catalog.py`.

## Source and style semantics

Canonical coordinates stay f64 in EPSG:4326 or EPSG:3857; projected f32 buffers
and Scene metadata are rebuildable caches. The compiler leaves source planes
unchanged. Null and hidden rows retain identity/state metadata but emit no
geometry, labels or density membership. Ordered layers and source rows determine
paint order. The pick key is `(layer_id, feature_id)`, retaining every u64 bit;
repeated IDs within a layer select the union of their eligible source rows.

Style precedence is base, scalar channel, feature patch, selected, hovered,
focused. Hidden state suppresses output. Opacity is resolved once into RGBA8.
The public catalog accepts explicit RGBA8 and CSS-pixel dimensions; it does not
inherit arbitrary CSS color strings from ordinary chart marks. Bubbles need
explicit increasing value and diameter domains and interpolate area. Choropleth
needs an explicit increasing value domain and at most 256 RGB stops. Arcs are
bounded sampled Mercator cubics, not geodesic or terrain paths; bend is in
[-1,1] and sample steps in [1,256].

Density counts visible point vertices and deduplicates source-row contributors
within each bin. A MultiPoint row may contribute to several bins. Its complete
CSR membership is retained; the aggregate explicitly reports dropped diameter,
symbol and stroke channels. State overlays preserve those channels. Bins are
half-open and exclude right/bottom boundary centers; ordinary point visibility
uses the projected center inside the viewport. Bounds describe projected
geometry, not glyph/stroke extents.

## Direct polygon fill admission

`crates/xyg-engine/src/geo_fill.rs` tessellates a closed screen-space shell
and its closed hole caches. Source f64 geometry and winding remain unchanged.
Horizontal slabs between vertex ordinates have constant edge order; shell
parity minus the union of hole intervals becomes bounded triangle records.
Ring orientation does not select fill semantics. Concave notches, touching
holes and overlapping hole intervals remain empty where appropriate.

An edge-order reversal inside a slab fails with `XYG_GEO_INVALID_ARGUMENT`
rather than emitting a fill for an unrecorded intersection. Open rings,
non-finite coordinates and painter-unrepresentable coordinate magnitudes
fail explicitly. A returned failure exposes no partial triangle output.

The direct processor admits at most 4,096 edges, 1,000,000 edge/slab visits
and 65,536 triangles. Exceeding a ceiling is `XYG_GEO_RESOURCE_LIMIT`. These
are direct tessellation limits, separate from GeoColumn source admission;
screen-bounded simplification and reduced spatial tiers belong to #50.
Tests independently pin filled area for holes, concavity and overlapping
hole intervals, and exercise malformed/resource/self-intersection failures.

## Shell boundary

A custom layer uses MapLibre's supplied WebGL2 context and current framebuffer.
XYG must preserve the basemap, GL state and shell scheduling through setup,
upload, paint, pick, error and disposal. It must not create another WebGL
context, clear the basemap or lose/resize the borrowed surface. Camera events
return to the Rust processor; MapLibre never draws XYG analysis features.

Reference: [MapLibre CustomLayerInterface](https://maplibre.org/maplibre-gl-js/docs/API/interfaces/CustomLayerInterface/).
The pinned shell conformance fixture uses locally packaged MapLibre 6.13.0,
with network access disabled and explicit CSP worker assets.

The shell preserves the application's provider configuration and attribution.
Rust labels and resolved SVG legends attach to the map container without
another canvas or GL context. Borrowed views reject padded layouts, title,
colorbar and annotations. The application forwards camera snapshots through
the Rust camera/catalog seams. See [external-gl.md](external-gl.md) for
transactional replacement, error cleanup and context-loss recovery proofs.

## Python composition

The public composition surface exports `geo_layer(kind, source=..., layer_id=...,
**properties)` and `geo_chart(*layers, camera=..., legend=..., budget=...)`.
The seven kinds are `points`, `bubbles`, `routes`, `arcs`, `polygons`,
`choropleth`, and `density`. Labels and legend entries are authored layer
properties. Source is a typed GeoArrow descriptor or packed XYGD; all style,
value, state, label and domain properties follow the shared catalog protocol.
Python adds no projection, style defaults or selection policy.

`GeoChart.compile()` returns the Rust Scene and exact layer/source metadata.
`compile(event=...)` invokes the same bounded Rust interaction seam.
`to_svg()`, `to_image(format, scale=..., quality=...)` and
`write_image(path, ...)` reuse ordinary native Scene export for SVG, PNG,
PDF, JPEG and WebP. The camera and canonical source arrays remain unchanged.

Node exports `encodeGeoCatalogRequest`, `geoCatalogCompile` and
`decodeGeoCatalogResponse`; browser exports the same framing helpers with
`XygWasmWorker.geoCatalogCompile`. Browser `XygGeographicChart` compiles and
prepares the Scene, hydrates an owned view or calls an app-supplied layer's
`setPrepared`, and exposes `ready`, `interact`, `updateCamera`, `snapshot` and
`dispose`. Its callbacks observe accepted Rust output; callback errors cannot
undo an accepted transition. Python uses snake_case property names;
Node/browser use camelCase and bigint IDs. Copyable examples are in
[api-examples.md](../api/api-examples.md#geographic-catalog).

## Interaction and accessibility

The bounded Rust index consumes authoritative decoded Scene primitives. Point
hits follow paint order; markers use the shared painter distance field,
segments use stroke distance, and triangle tests preserve polygon holes.
Density queries return actual nontransparent cell contributors. Events are
Hover, SelectAt, Brush, Clear, FocusStep, FocusFeature and SelectFeature;
selection modes are Replace, Add and Toggle. Invalid events publish no partial
Scene or state. State flags are hidden=1, selected=2, hovered=4 and focused=8.

The browser controller forwards pointer hover, click and Shift-drag brush
events. A brush owns one pointer through the shared capture policy: foreign
pointer events cannot finish or cancel it, capture loss cancels it, and synthetic
capture rejection still permits an explicit matching brush completion. Disposal
suppresses queued DOM-event error callbacks. Ctrl/Meta toggles selection. Arrow keys walk Rust's valid, nonhidden
feature order, including offscreen features; Enter/Space selects focus and
Escape clears interaction state. A 50-row paged companion table exposes all
eligible source rows and exact layer/feature IDs. Camera updates preserve the
full-u64 focus key and retained flags. Disposal cancels work, removes owned DOM
and restores borrowed surface attributes; it does not dispose the app's Worker.

## Bounded evidence and remaining work

The catalog admits at most 64 layers, a 64 KiB–384 MiB request budget and
256 MiB per XYGD source. Ordinary Scene record/style/image ceilings still
apply. Labels admit at most 128 entries and 8192 combined UTF-8 bytes; density
admits at most 4096 cells per axis and two million total image pixels.
Interaction adds independent limits of
one million indexed source rows, 131072 primitives, 1048576 grid entries,
65536 event candidates and four million primitive-work units. Transport and
compiler peak accounting include retained sources, scratch, metadata and output;
exceeding a ceiling fails atomically with `XYG_GEO_RESOURCE_LIMIT`.

Local proofs cover all seven native/WASM catalog families, exact u64 metadata
and GPU picks, state precedence, holes and shared-edge alpha, density color and
membership, keyboard/offscreen focus, companion paging, camera continuity,
strict CSP, borrowed framebuffer/state restoration and context recovery.
Commands and fixtures are linked from the capability matrix. Final review,
required CI and merge-queue integration remain release gates.

These direct fixtures do not establish massive-scale performance. Automatic
spatial tiers, screen-bounded simplification, disk-backed sources, temporal
filtering and tile/network budgets remain #50. Wider geographic projections
and complete SVG contour parity for uncommon glyphs are separate documented
gaps; current analytic glyph hit proofs do not claim vector contour identity.
