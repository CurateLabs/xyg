## Reproduction

Use Node22, Rust1.96, checkout Python via `uv --no-sync`, explicit
`XYG_NATIVE_LIB=$PWD/target/release/libxyg_core.so`, `TMPDIR=/var/tmp`, and a real
`XYG_CHROMIUM` path. Build native/client/module before the browser command.

```bash
uv run python scripts/gen_filter_paged_fixture.py generate target/filter-100m --rows 100000000
uv run python scripts/gen_filter_paged_fixture.py verify target/filter-100m --report target/filter-100m-verified.json
node scripts/filter_native_callback_browser.mjs target/filter-100m target/filter-100m-browser
XY_REQUIRE_BROWSER=1 uv run pytest -q tests/test_filter_native_callback.py
node --test packages/xy-node/test/filter-tier-c.test.mjs packages/xy-node/test/filter-tier-c-density.test.mjs
```
