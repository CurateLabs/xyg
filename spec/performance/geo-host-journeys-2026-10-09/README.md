# Bounded native geographic host journey evidence

Status: bounded implementation and evidence checkpoint. These are actual local frontend/runtime lifecycle proofs; no massive-source interactive
closure, performance comparison, network provider or deployment is claimed.

The three frontend fixtures reuse the canonical native geographic source from
`test_geoscale.source_fixture` / Node `geoscale-fixture.mjs`, through the existing
Rust source builder and retained coordinator. The query has an 800×600 EPSG:4326
camera, wrap enabled, bearing/pitch zero, exact u64 MAX layer/revisions and i64 MIN
instant. Uniform styling is explicit opaque red, diameter 6, transparent stroke.
The authoritative hit at CSS (400,300) includes the u64 MAX feature. A separate
32,769-row native test verifies reduced output and bounded membership paging.
Neither fixture serializes an entire source into the page or computes host LOD.

## Reproduction

From the host-journey checkout, build the native core and generated client using
repository commands. `XYG_NATIVE_LIB` may instead point to a verified matching
release dylib. Dependencies are test-local; no Jupyter/Reflex dependency is
introduced into plain XYG. On another platform substitute its core library,
installed Chrome/VS Code path and record its environment separately.

```sh
cargo build --release
npm ci
npm ci --prefix packages/xy-node
node js/build.mjs
uv venv .venv --python 3.13
uv pip install --python .venv/bin/python -r spec/performance/geo-host-journeys-2026-10-09/python-environment.txt
.venv/bin/python -m ipykernel install --prefix .venv --name xyg-geo-proof --display-name 'XYG geographic proof'
export XYG_NATIVE_LIB="$PWD/target/release/libxyg_core.dylib"
export XYG_CHROMIUM='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
PYTHONPATH=python:tests .venv/bin/python -m pytest tests/test_geo_host.py tests/reflex_adapter -q
XYG_GEO_NOTEBOOK_REPORT=/tmp/xyg-notebook.json node scripts/geo_notebook_host_smoke.mjs
```

Actual native/installed-Reflex suite: **159 passed**. This includes the
real authenticated ASGI/socket.io registry-miss rebuild and reconnect fixture;
it is not presented as the frontend proof. The production frontend is separate:

```sh
export XYG_GEO_ROOT="$PWD"
cd tests/reflex_geo_host_app
PYTHONPATH="$XYG_GEO_ROOT/python:$XYG_GEO_ROOT/tests" "$XYG_GEO_ROOT/.venv/bin/reflex" compile --dry
PYTHONPATH="$XYG_GEO_ROOT/python:$XYG_GEO_ROOT/tests" "$XYG_GEO_ROOT/.venv/bin/reflex" run --env prod --single-port > /tmp/xyg-geo-reflex-runtime.log 2>&1
# In another terminal at repository root, after the production-ready log:
XYG_GEO_REFLEX_REPORT=/tmp/xyg-reflex.json node scripts/geo_reflex_host_smoke.mjs
```

The fixture uses one local port 8139 for both production backend and frontend.
Stop only that owned application process after the probe. No external service
or deployed Reflex app is involved.

```sh
XYG_GEO_VSCODE_REPORT=/tmp/xyg-vscode.json \
 '/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code' \
 --user-data-dir /tmp/xyg-geo-code --extensions-dir /tmp/xyg-geo-code-extensions \
 --extensionDevelopmentPath="$PWD/tests/vscode_geo_host" \
 --extensionTestsPath="$PWD/tests/vscode_geo_host/test.cjs" \
 --disable-extensions --new-window --disable-workspace-trust \
 --disable-gpu-sandbox --enable-unsafe-swiftshader --use-gl=swiftshader
node --test packages/xy-node/test/geo-host.test.mjs packages/xy-node/test/vscode_contract.test.mjs packages/xy-node/test/no_browser_globals.test.mjs
```

Node contract guards: **4 passed**. Native cancellation tests gate real source
work and sender publication, cancel repeatedly, and prove registry guards and
queued buffer ACKs survive until settlement; failed rebuild cleanup preserves
active/mounted native owners. Client build/typecheck, targeted Python
`ty check`, full-worktree Ruff check/format and `git diff --check` pass.

## Remaining gates

The admitted presentation is one immutable native retained points frame per
adapter. Remote frontend/IPC/GPU/DOM memory is separate from the native process
ledger. Indexed native-host remount/independent Data duplication, native live pan/update, orphan recovery after loss of an unacknowledged
widget/Reflex realm, multiple retained sources/layers and massive interactive
indexed processing remain gates. Actual VS Code realm death is independently
proved; mere socket disappearance does not permit native ownership release.
See [geographic-hosts.md](../../design/geographic-hosts.md) for the framing,
copy/lease policy and public integration boundaries.
