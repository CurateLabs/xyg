# Stock Notebook7 native graph region selection

The existing native graph region harness now selects an explicit actual
frontend: JupyterLab by default, or `--frontend notebook7`. Application name,
major version, namespace, final route and loaded static assets must match the
requested frontend. A Notebook7 request cannot silently execute JupyterLab.
Kernel readiness still requires the named idle kernel. There is one shared
interaction/oracle body, not a second renderer or frontend-specific predicate.

Both frontends run at DPR1 and DPR2 against the reviewed31b4b06b native/client
cohort. Every existing assertion remains: trusted box and concave lasso; exact
node/edge UUIDs and result rows; parallel edges/self-loop and crossing-edge
exclusion; actual WebGL masks; selected/unselected node/edge pixels; real native
owner-table capacity refusal/recovery; complete refused-history camera/RGBA;
combined API patch/Back/Forward; pan/wheel; peer isolation; no external requests
or page errors; and disposal. These are source-checkout tests in installed
applications, not published-wheel or desktop region qualification.
