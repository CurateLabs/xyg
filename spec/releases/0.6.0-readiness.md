# XYG 0.6.0 publication readiness — 2026-10-23

**Status: not accepted for public publication.**
[#108](https://github.com/CurateLabs/xyg/issues/108) remains the acceptance
authority. Preparation, schema qualification, a green required CI aggregate,
and registry access each establish only their stated scope.

## Completed prerequisite work

- XYG owns the result-disposition ledger. Ledger version 2 includes explicit
  derived endpoint pairs for Core `bfs_depth` and `dijkstra_cost`, preserving
  source/target UUIDs and cost without inventing a path or persisted edge.
  Unsupported schema versions retain their stable error code and name the
  schema and next action. This work landed independently in PR #1061.
- [The packaged compatibility declaration](../../python/xyg/graphforge-compatibility.json)
  binds authentic Core `0.5.2` and `0.6.0-rc.5` registry and IPC corpora to
  immutable source and evidence hashes. Rust checks Core's exported field and
  algorithm contracts; [the corpus instructions](../../tests/fixtures/graphforge/core/README.md)
  describe reproduction. This qualification concerns result schemas; the
  selected launch pairing still requires the separate #108 acceptance.
- The guarded publisher covers all seven npm packages, including the browser
  package, validates aligned versions and browser asset hashes, and preflights
  existing immutable npm versions before any new upload. PyPI requires the
  complete npm cohort and both registry opt-ins. GitHub prereleases use the
  canonical version parser and cannot become the latest stable release.
- [Retained browser evidence](../performance/rc-readiness-2026-10-22/README.md)
  proves six bounded density no-refinement cases through the ESM and IIFE
  entries. The report contains exact artifact/harness hashes, screenshots,
  resource cleanup, CSP, and limitations. It does not replace the full browser
  foundation gate or the real packaged Reflex journey.
- The [public compatibility policy](compatibility-policy.md) records the
  required `0.6.x` commitment, two-minor/180-day deprecation rule, and exact
  internal binary boundaries. [Formats and migration](formats-and-migration.md)
  distinguishes canonical inputs from caches and records actual supported
  readers/rebuild paths. These are freeze preparation; the final classified
  API inventory and exact accepted artifacts remain required.
- The [source API inventory](api-inventory.md) detects declared surface drift
  across hosts and references ABI 395. Its explicit classification and
  behavioral gaps remain acceptance work; successful generation or tests do
  not establish the final freeze.
- The [tile-keyed painter](../design/density-tile-painter.md) implements the
  bounded native spill/reuse path, including binary observed inventories,
  source-level textures, and adjacent-level transitions. [Retained bounded
  spill evidence](../performance/tile-spill-bounded-2026-10-23/README.md) records
  Python/Node oracles and actual transfer/residency counters. It does not
  satisfy the remaining #11 dedicated performance or full Phase-4 journeys.
- [Initial source-browser validation](../performance/density-tile-cache-2026-10-23/source-browser-validation/README.md)
  retains the full foundation and interaction results against hashed changed
  assets. An earlier disposal page error remains unreproduced; its diagnostic
  and baseline comparison are retained without a runtime-fix claim. Final
  candidate acceptance must evaluate that qualification explicitly.
- [Post-review client validation](../performance/density-tile-cache-2026-10-23/review-followup/README.md)
  supersedes the initial client for bounded viewport admission and safe fade
  retirement when Rust's retained inventory shrinks. The prior wheel and
  browser snapshots retain their original hashes; final packaged acceptance
  must use the corrected client.
- [Installed-wheel Reflex and export evidence](../performance/packaged-reflex-2026-10-23/README.md)
  exercises an actual compiled `XYChart` application: primary, secondary and
  polar WASM ticks; missing/corrupt tick modules failing closed; and live
  unsupported density refinement. Actual Python HTML exports also retain
  their overview under missing/corrupt optional modules. All eight cases
  pass against one hash-verified worktree wheel. The six Reflex cases describe
  the current branch before the support removal in #1063; they do not satisfy
  the amended #886 supported-consumer acceptance. The Python HTML cases remain
  applicable shared proof. #54 still requires the final immutable candidate.
